# Security

This repo is mostly links, so most security issues belong to the project being linked to.

- **A vulnerability in a listed project**: report it to that project first. If it doesn't respond
  within 30 days, or the issue puts users at risk, open a
  [private security advisory](../../security/advisories/new) here and we'll review whether the
  entry should be flagged or removed.
- **A verified entry whose WASM hash no longer matches its source**: open a private security
  advisory. We'll remove the **Secured on T3N** badge while we look into it.
- **An issue in this repo's own scripts or workflows**: open a private security advisory.

Please don't open public issues for any of these.
