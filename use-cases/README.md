# Use cases

Each page takes one problem, shows the pattern that solves it, and points to code you can run.

| Problem | Pattern |
| --- | --- |
| An agent needs someone's personal data to complete a booking or purchase | [Blind booking](blind-booking.md) |
| An agent holds a payment credential and could overspend | [Spend limits](spend-limits.md) |
| An agent needs a fact about a person ("over 18?"), not their record | [Yes/no checks](yes-no-checks.md) |

Have a pattern that belongs here? Open a pull request with a new page in this folder.
